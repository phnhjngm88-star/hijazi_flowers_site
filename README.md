# Hijazi Flowers & Plants Website

Official bilingual website starter for Hijazi Flowers & Plants.

## Update products

Open `products.js` in this repository and click the pencil icon to edit.

Each product has:
- `category`: flowers / plants / trees / nursery
- `en`: English product name
- `ar`: Arabic product name
- `descEn`: English description
- `descAr`: Arabic description
- `price`: USD price, e.g. `$35`
- `image`: direct image URL

Duplicate a product block to add more items, then commit the changes. The public website updates automatically after deployment.
